# Визуальный редизайн

Технически ничего не менялось: сборка, чанки, JS-логика, классы, на
которые опирается JS (`.C_Dropdown`, `.A_FilterTag.active`,
`.O_MenuLinks` и т.д.), — всё как было. Переработаны только CSS
(значения, не архитектура вёрстки) и наполнение нескольких страниц,
которые раньше были пустыми заглушками.

## Система дизайна (`src/stylesheets/basic.css`, блок `:root`)

- **Цвет** — графитовый текст (`--ink`) на тёплом белом (`--paper`),
  один зелёный акцент (`--accent`) вместо фиолетово-неонового
  градиента и заливок. Янтарный/красный — только для точечных
  предупреждений и результатов тестов.
- **Типографика** — шкала `--fs-xs … --fs-hero` (13–92rem), тот же
  шрифт PT Root UI, что и был (уже лежал локально в `src/fonts`).
- **Отступы** — шкала `--space-1 … --space-8` (8–96rem).
- **Форма** — сдержанные радиусы `--radius-sm/md/lg` вместо
  пилюль-кнопок и `border-radius: 40rem` почти на всём.
- Старые имена переменных (`--bg-card-color`, `--button-basic-color`
  и т.д.) оставлены как алиасы новых токенов — это позволило не
  трогать сами объявления `var(--...)` по всем component-css файлам.

vw-rem-скейлинг (`html { font-size: calc(1vw / 14.4) }`) и структура
`01_quarks … 07_superorganisms` не менялись — редизайн лёг поверх
существующей методологии, а не заменил её.

## Контент, которого раньше не было

Несколько страниц были буквально пустыми заглушками (`<h1>` и
навигация, без единого абзаца) — редизайн стилей на пустой странице
показать нечего, так что здесь я добавила реальный текст:

- `pages/articles/{aloe,cactus,monstera,orchidea,sansevieria,article1}.html`
  — раньше только `<h1>Алоэ</h1>`, теперь настоящие статьи: подводка,
  разделы по уходу, таблица характеристик, похожие статьи.
- `pages/dictionary.html` — был пустой `<h1>Словарь</h1>`, теперь
  словарь на 15 терминов с фильтром по первой букве (маленький
  инлайн-скрипт в самой странице, по образцу уже существующей формы
  подписки на `index.html` — JS-архитектуру проекта не трогала).
- `styleguide.html` — lorem ipsum заменён на реальное описание новой
  системы дизайна, с цветовыми свотчами.
- `pages/theory.html` — был совсем пустым HTML-скелетом под
  JS-упражнение (`theory.js` пишет в консоль и открывает alert) — не
  стала выдумывать несвязанный контент, оформила как есть.
- `pages/articles.html` — секция `.O_Articles` рендерится через JS
  (`articles.js`), который тянет карточки из Airtable, но сам вызов
  закомментирован в коде (значит секция и была пустой). Добавила
  статичные карточки той же структуры — при включении JS-рендера в
  будущем это место просто станет динамическим.
- `index.html` — три карточки-тизера статей вели на один и тот же
  плейсхолдер `article1.html` с текстом «Заголовок статьи» — заменила
  на три реальные разные статьи; убрала lorem ipsum в двух подводках.

## Что не трогала

- `search.html`, `tests.html`, `pages/tests/test1.html`,
  `pages/reactBasics.html` — контент там уже был реальным (тестовые
  вопросы, расписание воркшопов), только новая стилизация.
- Разметку `<nav class="S_Menu">` на внутренних страницах не
  переструктурировала — она и так была одинаковой почти везде,
  просто получила новую стилизацию.
